# Brawl Chess (version JavaScript)

Jeu mobile multijoueur de combat d'échecs 1v1, inspiré de Clash Royale. Client en Vue.js (`client/`), serveur Node.js + Express (`server/`).

## Lancer

```bash
cd server && npm install && npm start
cd client && npm install && npm run dev
```

Le prototype d'origine (Love2D) est dans [Brawl-Chess](https://github.com/LBasil/Brawl-Chess).
